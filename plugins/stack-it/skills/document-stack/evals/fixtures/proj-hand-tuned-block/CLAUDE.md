- Vitest 3.0.7: test framework

### Commands

- Dev: `pnpm dev`
- Build: `pnpm build`
- Test: `pnpm test`
- Lint: `pnpm lint`

### Gotchas

- pnpm does not hoist. A package you import but never list in `package.json` resolves in local dev and fails at runtime on the build box; add it explicitly.
- Turbopack serves stale CSS after renaming a module. Restart the dev server; a hard refresh does not clear it.
