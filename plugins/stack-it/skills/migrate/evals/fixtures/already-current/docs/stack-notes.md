# Stack notes

## Runtime and tooling

| Tool | Version | Detail |
|---|---|---|
| Python | 3.14.3 | Language and runtime. Installed system-wide; the project environment is uv's. |
| uv | 0.6.12 | Package and environment manager. `uv sync` resolves from `pyproject.toml`, and every command runs through `uv run`. |
| pytest | 8.3.0 | Test framework. httpx provides FastAPI's TestClient transport, so it is a dev dependency even though no test imports it directly. |
| Ruff | 0.8.0 | Linter and formatter, both from one binary. Configured in `pyproject.toml`; there is no separate config file. |

## Application

| Tool | Version | Detail |
|---|---|---|

| uvicorn | 0.34.0 | ASGI server, installed with the `standard` extra. Used for local runs and for the runtime check. |
| SQLModel | 0.0.22 | ORM over a local SQLite file. The lifespan handler creates the tables at startup, so there is no migration tool in the stack. |
