# Stack

- Python 3.14.3: language/runtime
- uv 0.6.12: package and environment manager
- FastAPI 0.115.0: web framework
- uvicorn 0.34.0: ASGI server
- SQLModel 0.0.22: ORM, backed by a local SQLite file
- pytest 8.3.0: test framework (httpx provides the TestClient transport)
- Ruff 0.8.0: linter and formatter

## Commands

- Test: `uv run pytest`
- Lint: `uv run ruff check .`
- Format: `uv run ruff format .`
- Run: `uv run uvicorn app.main:app --reload`

## Conventions

- Tests live in `tests/` and import the app as `app.main`.
- The SQLite file is created on startup by the lifespan handler; there is no migration step.
