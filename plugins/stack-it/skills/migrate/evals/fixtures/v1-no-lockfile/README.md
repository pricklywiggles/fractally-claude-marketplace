# Acme Internal Service

A small internal todo API that the ops team uses to track migration tasks.

## Tech Stack

- FastAPI 0.115.0 behind uvicorn 0.34.0
- SQLModel 0.0.22 over SQLite
- pytest 8.3.0 for tests, Ruff 0.8.0 for lint and format

## Getting Started

1. `uv sync`
2. `uv run uvicorn app.main:app --reload`
3. `uv run pytest`
